# v0.8.6 → v0.9.0 변경 요약

**작성일**: 2026-05-12
**작성 배경**: 회장님 2026-05-12 피드백 + 호현쌤 채팅 지시 반영

## 구조

- **유지**: 4부 체제 (비전 / 개인+공동체 변화 / 질서 붕괴+새 사회계약 / 연구 계획)
- **유지**: P1, P3, P4 거의 그대로
- **강화**: P2만 본격 강화 (2.1 확장, 2.3 신설, 2.4로 공동체 절 이동)

## P2 강화 핵심 3가지

### 1. 시대별 "인류가 풀어야 했던 문제 = 직업"의 역사 추가 (2.1)

기존 표에 두 컬럼 추가:
- **인류가 풀어야 했던 문제**
- **그 문제를 풀던 직업**

시대 행도 확장:
- 농업 / 산업 / 정보화 (기존) + **AI 에이전트 / 휴머노이드 2050** (신규)

회장님 지적("미래 변화 속에서 어떤 정체성을 요구하는지를 알아야")의 직접 반영. 직업이 먼저 정의되어야 정체성과 매칭할 수 있다는 논리.

### 2. 휴머노이드 시대 묶음직업 매트릭스 신설 (2.3)

100년 전 사람이 디자이너·엔지니어를 예측해야 했듯, 2050년의 직업을 구체적으로 예측. 9개 묶음직업 + 매칭되는 정체성 특성:

- 정체성 탐험가 (Identity Navigator)
- 질서 설계자 (Order Architect)
- 생태계 직조가 (Ecosystem Weaver)
- AI-인간 조율자 (Human-AI Mediator)
- 경계 감시자 (Frontier Sentinel)
- 통합 건강 설계자 (Whole-Life Health Designer)
- 돌봄 통합가 (Care Integrator)
- 세계관 창작자 (World Builder)
- 진실성 검증자 (Truth Verifier)

공통 패턴: 지금 분리된 기관들(병원·학교·시청·방송사·법원)이 분산 담당하던 일을 한 사람이 통합 제공. 기관이 하던 일이 정체성을 가진 개인으로 내려온다.

시간 단위 변화도 명시: "하루 8시간 한 가지 일" → 문제 단위 직업.

### 3. 공동체 재구성 절을 "직업-정체성 매칭"의 논리적 귀결로 재배치 (2.4)

기존 2.3 → 2.4로 이동. 도입 문장 추가:

> "미래 직업이 정체성에 매칭되려면 그 정체성을 발견·훈련할 수 있는 공동체가 필요하다. 변화는 개인 → 가족 → 이웃 → 마을 → 도시 → 국가 → 세계의 논리적 귀결로 이어진다."

가정·이웃·마을·도시·국가·글로벌 각 항목의 "디지털시대 재균형" 문구를 정체성 발견·매칭 관점으로 재정렬:
- 가정: "노동력 재생산" → "정체성 발견의 첫 단위"
- 이웃: "비공식 돌봄" → "다양성 노출의 장"
- 마을: 정체성 훈련의 규모
- 도시: 정체성-직업 매칭 생태계 (강소도시 + 시산학)
- 국가: 다양성·안전망의 큰 틀 설계자, 실행은 도시로
- 글로벌: 미션 한정 거버넌스

마지막 줄 추가: "시장이 만들지 못하는 일자리(돌봄·정체성 발견·공동체 의례)를 도시가 보장해야 사회가 유지된다."

## 호현쌤이 가장 주목할 부분

**2.1 표의 5번째 행(휴머노이드 2050)** — "묶음직업" 한 칸이 본 마스터플랜 전체의 새 축입니다. 이 축이 받아들여지면 2.3 묶음직업 매트릭스와 2.4 공동체 재구성이 자연스럽게 따라옵니다. 이 한 칸이 흔들리면 P2 강화 전체가 흔들립니다.
